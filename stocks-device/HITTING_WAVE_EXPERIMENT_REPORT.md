# Hitting Wave Starts — ניסוי ראשוני על 20 מניות

תאריך הרצה: 2026-08-04. זהו ניסוי רטרוספקטיבי נפרד ואינו משנה את `Freq Q`
או את הדשבורד.

## שאלת הניסוי

האם אפשר לקחת עד שלושה תדרים שנבחרו כיום במודל K3, להזיז חלון אימון ובדיקה
יום אחד בכל פעם, לזהות את תחילת רצף ההתאמה האחרון של כל תדר ולמצוא חדשות
שפורסמו מהמסחר הקודם ועד פתיחת יום תחילת הרצף?

שם העבודה שנבחר: `Hitting Wave Start`. השם מתאר היפותזה שלפיה הפרעה חיצונית
יכולה להתחיל דפוס תנודות. הוא אינו קביעה שהכתבה שנמצאה גרמה לתנועה.

## המדגם

AAOI, COHR, BA, AJG, AAPL, MSFT, NVDA, AMD, AVGO, MU, TSLA, META, AMZN,
GOOGL, NFLX, PLTR, QCOM, ANET, GE ו־CCL.

נבדקו שלושה תדרי K3 לכל מניה: 60 תדרים בסך הכול.

## חישוב Rolling OOS

לכל תקופה נוכחית `P`:

```text
train = max(14, ceil(3 × P))
validation = max(4, ceil(0.20 × train))
```

החלון זז יום מסחר אחד בכל בדיקה. התדר הנוכחי מותאם יחד עם intercept ומגמה
על חלון האימון, ולאחר מכן המקדמים נשארים קבועים בחלון validation.

```text
NRMSE = RMSE(validation residual) / reference oscillation scale
OOS Q = 1 / (1 + NRMSE)
```

נבדק גם שהתדר המבוקש הוא peak מקומי בספקטרום ונמצא עד 20% מתקופת היעד.

```text
Rolling Q = OOS Q^0.80 × spectral strength^0.20
good = Rolling Q >= 0.55 and spectral peak present
```

זהו ציון ניסויי חדש, לא נוסחת `Freq Q` הקיימת.

## סיווג המצב

- `active`: נקודת הבדיקה האחרונה עוברת.
- `weakening`: האחרונה אינה עוברת, אבל עדיין לא הצטברו מספיק כישלונות לאישור
  שבירה.
- `broken`: רצף הכישלונות עבר את hysteresis.
- `insufficient`: אין די נתונים או לא נמצא peak מתאים.

מספר הכישלונות לאישור שבירה:

```text
max(2, ceil(P / 4))
```

## מגבלות קריטיות

1. התדרים הם התדרים שנבחרו היום; מעקב אחריהם לאחור הוא ניתוח רטרוספקטיבי.
2. Google News אינו ארכיון מחקרי מלא. אפס תוצאות אינו מוכיח שלא היו חדשות.
3. בחלק מהתוצאות שעה `03:00` היא timestamp מקורב של Google ולא בהכרח שעת
   הפרסום המקורית.
4. מניות פופולריות מקבלות כתבות כמעט בכל יום. שיעור 39/46 אינו מוכיח קשר.
5. בחירת השמות והספים נעשתה לפני control group מלא.
6. שלושה תדרים של אותה מניה יכולים לקבל אותו תאריך התחלה; אין לכפות תאריכים
   שונים אם הנתונים אינם תומכים בכך.

## הניסוי הבא הנדרש

עבור כל Hitting Wave Start יש לבחור מספר תאריכי ביקורת מותאמים:

יש להשוות:

- מספר אתרי חדשות ביום שלפני Hitting Wave Start מול ימי הביקורת.
- שיעור כותרות earnings, guidance, contract, regulation, analyst action וכו'.

רק אם Hitting Wave Starts מקבלים כיסוי חריג משמעותית מה־baseline יהיה מוצדק
להוסיף ציון לדשבורד.
